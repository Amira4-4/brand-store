# Hurra Store (حُرّة)

An Arabic RTL e-commerce storefront for modest fashion, built with React, Vite and Bootstrap.

**Live demo:** https://amira4-4.github.io/brand-store/

## Features

- Responsive layout for mobile, tablet and desktop
- Fixed navbar with search, favorites and shopping cart
- Cart and favorites saved in the browser (localStorage)
- Category tabs
- Scroll-reveal animations and hover effects
- Full Arabic support with RTL layout

## Tech stack

React, Vite, React Router, Bootstrap, React Icons, JavaScript, localStorage

## Run locally

```bash
npm install
npm run dev
```

This is a frontend-only portfolio project. There is no backend or payment processing.

Built by Amira Mahmoud.
